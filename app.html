Fórmulas aplicadas

Valor Presente Neto (VPN)
VPN = −P + FNE₁/(1+TO)¹ + FNE₂/(1+TO)² + ... + FNEₙ/(1+TO)ⁿ
🟢 VPN > 0 → Es viable (Ganancia) 🔴 VPN < 0 → No es viable (Pérdida) ⚖️ VPN = 0 → Indiferente
Tasa Interna de Retorno (TIR)
Inversión₀ = FNE₁/(1+TIR)¹ + FNE₂/(1+TIR)² + ... + FNEₙ/(1+TIR)ⁿ
🟢 Tasa descuento < TIR → Es viable (Ganancia) 🔴 Tasa descuento > TIR → No es viable (Pérdida) ⚖️ Tasa descuento = TIR → Indiferente

P / Inversión₀ = Inversión inicial  |  FNE = Flujos netos de efectivo

TO = Tasa de oportunidad del inversionista  |  TIR = Tasa Interna de Retorno
